## 判定: **ドリフトなし** → 星型を既定に採用

事前登録の基準を機械的に適用した結果、**mae と hist の両方**で
「ドリフトなし」(`|d(NB3) - 星型最大| <= 星型幅`)が成立した。

### 基準の適用

| 指標 | 星型最大 | 星型幅 | ドリフト判定閾値 | NB3 | 判定 |
|---|---|---|---|---|---|
| mae | 25.704 | 9.337 | 35.041 | 23.334 | **ドリフトなし** |

両指標が一致。事前登録の対応表により:

- **採用する鎖 = 星型**(各原画Aは正史立ち絵から直接生成する)
- **`docs/09 §9-3` 差し戻し粒度 = カット単位**(カットが独立するため撮り直しが安全)

補助基準(単調増加)は両指標とも不成立(NB2 > NB3)。累積劣化の兆候は見られなかった。

## この判定の限界(重要・過大評価しないこと)

**「ドリフトを検出しなかった」であって「ドリフトが無い」ではない。** 検出力が低い。

- 照合カット後の画像は正史から mae 16〜26 / hist 0.65〜0.78 離れている。
  **別キャラ同士(虎爺 vs 栞)の hist 0.612 より遠い**。すなわちこの指標は
  キャラの同一性ではなく**依然として構図とスケールの差を測っている**
- 原因: 照合カットで姿勢は揃ったが、**画面内でのキャラの大きさが揃っていない**。
  正史はキャラが大きく写り、照合カット出力は小さく写るため、背景面積の比率が
  ヒストグラムを支配する
- したがってノイズ幅が大きく(mae 9.3 / hist 0.12)、**小さなドリフトは埋もれる**

各条件1サンプルであることも併せ、**本結果は「大きな累積劣化は起きていない」までしか
主張しない**。

## 目視観察(基準外・参考)

- 星型 A1〜A3、直列 B1〜B3 とも、**3回の実変換を通してキャラは保たれていた**。
  顔・眼鏡・髪・カーディガンいずれも正史と同一と見なせる
- 直列の B3(世代3)も崩れていない
- 第1版(docs/11)で見られた「世代が進むと人物が大きくなる」現象は、
  **実変換を挟むと再現しなかった**。あれは再エンコードに固有の現象だった可能性が高い

## P1: 挙動プローブ

「入力の素性ではなく、要求した変換の大きさで挙動が決まる」という見立ての検証。

同一入力 `B1` に**大きな変換**(C1の引き→C3の横顔寄り)を2回要求した結果:

| 要求した変換の大きさ | 出力どうしの mae | 出典 |
|---|---|---|
| ほぼ無し(再エンコード) | **1.5 〜 3.1** | docs/11 |
| 中(正史→中立立ち姿) | **10.4 〜 15.0** | docs/11 |
| **大(引き→横顔寄り)** | **45.4** | 本検証 P1 |

**要求変化量に対して出力のばらつきが単調に増加した。** 見立てを支持する。

ただし内部機構は **UNKNOWN**。観測できるのは「要求変化量が大きいほど出力が
ばらつく」という挙動のみであり、別アルゴリズムの存在を示すものではない。
また C3(横顔寄り)自体が構図の自由度が高い指示であるため、
**変換の大きさと構図の自由度が分離できていない**(交絡が残る)。

### 実装への含意(仮説・未検証)

原画生成を**一度の大跳躍ではなく小さな変換の連鎖に分解**した方が、
出力が安定する可能性がある(例: 正史 → 中立立ち姿 → カット構図)。
**未検証のため設計には反映しない。** 検証するなら別途 run を立てる。
