## 3. ツヅリ

- 正史立ち絵: [characters/tsuzuri_canon.png](characters/tsuzuri_canon.png)

### 分類の決定(2026-08-03 豆虎承認)

**機械。ただしロボットではなく「からくり」。虎爺が手ずから組んだ一点物の自動人形。**

「生き物か機械か」で設計が止まっていた点への回答。**ロボット(工業製品)として読むと中途半端だが、
からくり(手仕事の一点物)として読むと全部説明がつく**、という整理を採る。

- 精巧なのに動力が原始的 → 手製だから
- 生き物にしか見えないのに機械 → それが職人の腕自慢だから
- キーが剥き出しで背中に刺さったまま → 隠す気がないから。虎爺の署名

### 確定ルール

| 項目 | 決定 |
|---|---|
| 分類 | からくり(手製の自動人形)。**生物ではない** |
| 製作者 | 鍛治虎三(虎爺) |
| 動力 | ゼンマイ。**背中のキーは常時装着**。外れない・外さない |
| 発話 | **しない**。鳴き声と仕草のみ |
| 生理 | 食べない・眠らない・**死なない**。ただし**止まる**・壊れる |
| 修理 | 虎爺のみ |
| 見た目 | `tsuzuri_canon.png` を正史とする。羽毛の質感は本物でよい(本物の羽を使っているため) |
| 描画の絶対条件 | **キーを必ず描く**。省略された絵は不採用 |
| 役割 | 外に出て見てくる/持ち帰る。綴じるのは栞 |

「発話しない」は `app/config.py` の `cast` にツヅリの声定義が無いことと整合する
(ツヅリは**語られる側**であり、名前の読み方は栞・虎爺の演技指示に含まれている)。

### 番組構造への利用

ゼンマイ動力のため**稼働時間に限りがある**。これを演出の区切りに使える。

- ツヅリが飛べる = その回の取材パート
- ゼンマイが切れて止まる = 区切り。栞が巻き直して次のパートへ

### 描画方針(重要)

**ツヅリは生成AIの描画対象から外す。** 正史PNGから切り出したスプライトをプログラムで合成する。

理由: 画面内で40px前後にしかならないため、ネジ巻きキーのような小物は生成では構造的に潰れる。
実際に `s1_genga_board.png` のK2(頭上)・K5(飛翔)では**キーが両方とも消失している**。
`docs/04` の原則「AIに絵作りをさせない/見た目はデータで固定する」をそのまま適用する。

2026-08-03の検証で、K5の飛翔ポーズ(原画のまま)にキーだけを合成する方式が成立することを確認済み。
