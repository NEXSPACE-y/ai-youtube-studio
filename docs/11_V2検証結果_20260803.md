## 判定不能になった原因(方法論上の発見)

星型サンプル同士・直列の隣接世代同士の距離を追加で測ったところ、
**2指標がまったく別のものを測っていた**ことが分かった。

| 組 | mae | hist |
|---|---|---|
| S1 vs S2 | 12.017 | 0.0705 |
| S1 vs S3 | 10.353 | 0.0545 |
| S2 vs S3 | 14.990 | 0.0377 |
| D1 vs D2 | 1.551 | 0.1275 |
| D2 vs D3 | 3.061 | 0.1064 |
| D1 vs D3 | 4.275 | 0.2038 |

- **星型**: 互いに mae は 10〜15 と大きいが hist は 0.04〜0.07 と小さい
  → 構図・スケール・立ち位置は毎回ばらつくが、**色とパレットは揃っている**
- **直列**: 隣接世代の mae は 1.5〜3 と小さいが hist は 0.11〜0.13 と大きい
  → 構図は前の絵をなぞるので揃うが、**色とパレットが世代ごとにずれていく**

つまり **mae は構図ノイズに支配されており、キャラの同一性を測れていない**。
星型の mae が大きいのは「キャラが崩れたから」ではなく「毎回違う画角で描かれたから」である。

**この知見をもって基準を後から差し替えることはしない。** docs/10 は変更せず、
別の事前登録(V2-A2)を新規に起こして再検証する。
