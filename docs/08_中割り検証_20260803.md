## 0. 前提の訂正

`s1_genga_board.png` の K1〜K8 は **1カットの原画ペアではなく、8つの別カット**(絵コンテ)である。
K1とK2、K3とK4はカメラも背景も異なるため、そのまま `last_frame` に渡しても
「中割り」ではなく「別カット間のモーフ」になる。

そこで **原画Aから画像モデルで「姿勢だけ変えた原画B」を生成**し、正しいA/Bペアを作ってから検証した。

## 1. 手順

1. `s1_genga_board.png`(2660x1480)を8枚の640x640に分割
2. K2 / K4 をそれぞれ16:9に切り出して**原画A**とする
3. `gemini-2.5-flash-image` に原画Aを渡し、「画角・背景・画風は完全に維持、姿勢だけ変更」
   と指示して**原画B**を生成
4. `veo-3.1-lite-generate-001` に `image`=原画A、`config.last_frame`=原画B を渡して8秒生成

使用パラメータ:

```
model             veo-3.1-lite-generate-001
location          us-central1        ← asia-northeast1 はメディアモデル404
aspect_ratio      16:9
duration_seconds  8
last_frame        原画B
generate_audio    False              ← 音声はTTSが担当
seed              20260803
negative_prompt   text, letters, subtitles, watermark, logo, extra characters,
                  camera shake, zoom, style change, 3d render, photorealistic
```

## 2. 結果

| 検体 | 動き | キャラの同一性 | 生成時間 | 出力 |
|---|---|---|---|---|
| 栞(K2起点) | 手を下ろす+口を閉じる | **8秒間 崩れなし** | 45秒 | 1280x720 / 24fps / 8.0秒 |
| 虎爺(K4起点) | 指差し→腕組み | **8秒間 崩れなし** | 45秒 | 1280x720 / 24fps / 8.0秒 |

- 2026-07のコトラ版テストフィルム([testfilm_poc.mp4](testfilm_poc.mp4))で発生していた
  「カット間でキャラが別人になる」現象は、**同一カット内8秒では観測されなかった**
- 背景の静止指示が有効に機能した
- **副次的観測**: 瞬きが自動で挿入される。虎爺は喋る動作に合わせて口が動く
  (`docs/06 §7` は口パクを「T1方式の重畳が現実解」としていたが、中割り区間内では自動で付く可能性)

## 3. 観測された課題

- 栞の前半でカメラ/スケールがわずかに揺れる(完全静止指示でも微動)
- 線が原画よりわずかに柔らかくなる。原画のシャープさから微妙に劣化
- 検証したのは8秒のみ。他の尺は未検証
- 原画Bは背景の細部が原画Aと完全一致しない(書架の本の並び等が微妙に異なる)
