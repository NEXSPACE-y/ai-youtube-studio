## 4. YouTube OAuthクライアント作成(豆虎の作業)

1. https://console.cloud.google.com/apis/credentials?project=ai-youtube-studio-503109 を開く
2. 「認証情報を作成」→「OAuthクライアントID」
3. 同意画面の設定を求められたら: User Type「内部」→ アプリ名「AI YouTube Studio」→ 保存
4. アプリケーションの種類:「デスクトップアプリ」→ 作成
5. JSONをダウンロードして `D:\ai-youtube-studio\client_secret.json` に保存
   (このファイルは .gitignore 済み。共有しないこと)

## 5. リフレッシュトークン取得(豆虎の作業)

```
cd D:\ai-youtube-studio
pip install google-auth-oauthlib
python tools/get_refresh_token.py client_secret.json
```

ブラウザが開くので、**投稿先YouTubeチャンネルのGoogleアカウント**でログインして許可。
表示された `refresh_token` をClaudeに「Secretに登録して」と渡す
(チャットに貼りたくない場合は、自分で以下を実行でもOK):

```
echo -n "トークンの値" | gcloud secrets versions add yt-refresh-token --data-file=-
```

client_secret.json の `client_id` / `client_secret` も同様に
`yt-client-id` / `yt-client-secret` へ登録する。
