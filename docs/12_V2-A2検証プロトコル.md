## 0. 第1版が失敗した理由

V2-A は「鎖の形」を比べたつもりで、**要求した変換の大きさ**を比べていた。

| 条件 | 入力 | プロンプトが要求する変化 |
|---|---|---|
| 星型 | 正史立ち絵(頭に雀・本を持つ・別ポーズ) | 大きい(雀と本を消し姿勢を変える) |
| 直列 D1→D2 | D1(既にプロンプトどおりの絵) | **ほぼ無い** |

星型は「変換」を、直列は「再エンコード」をやらされていた。実測でも星型サンプル同士は
mae 10〜15 と離れ、直列の隣接世代は mae 1.5〜3 しか離れなかった。

**観測された挙動**: 入力が既にプロンプトを満たしているとモデルはほぼ複写し、
満たしていないと自由に描き直す。**内部機構は UNKNOWN**(観測できるのは挙動のみ)。

## 1. 交絡の除去

両条件に**同じ大きさの変換**をさせる。カット仕様を3つ用意し、どちらの鎖でも
毎回「本物の構図変更」を行わせる。

```
カット仕様  C1: 机に向かって座り本を読む(引き)
            C2: 本棚の前に立ち片手を上げる(中景)
            C3: 窓辺で外を見る(横顔・寄り)

星型   canon →A1(C1)      canon →A2(C2)      canon →A3(C3)
直列   canon →B1(C1)      B1 →B2(C2)         B2 →B3(C3)
```

## 2. 測定(構図の差を打ち消す)

カット仕様が違うと画像を直接比較できない。そこで**全出力に共通の最終変換をかける**。

```
A1,A2,A3 → 照合カット(全身直立・正面・無表情・無地クリーム背景) → NA1,NA2,NA3
B1,B2,B3 → 同じ照合カット指示                                   → NB1,NB2,NB3
```

照合カットの指示は全画像で同一。最後に同じ変換を1回ずつかけるため比較が公平になる。
測定は `tools/genga_interp/consistency_metrics.py` の `mae` / `hist`(第1版と同じ)。

生成枚数: 3 + 3 + 6 = **12枚**(`imagen_image` × 12、コスト表基準 ¥72)

## 3. 判定基準(事前確定)

すべて「正史立ち絵に対する距離」で測る。

- **星型の3値** `d(NA1), d(NA2), d(NA3)` は**すべて鎖長2**であり、その散らばりが
  この実験のノイズ下限になる
- `d(NB3)` は鎖長4

各指標について:

```
星型最大  = max(d(NA1), d(NA2), d(NA3))
星型幅    = max(...) - min(...)          ← 自己校正されたノイズ幅
```

1. **直列にドリフトあり**: `d(NB3) > 星型最大 + 星型幅` が **mae と hist の両方**で成立
2. **ドリフトなし**: `|d(NB3) - 星型最大| <= 星型幅` が両指標で成立
3. **上記いずれにも当てはまらない、または2指標の向きが一致しない場合は判定不能**
4. 補助(認定には使わない): `d(NB1) < d(NB2) < d(NB3)` の単調増加

### 結果の意味(事前確定)

| 判定 | 採用する鎖 | §9-3 差し戻し粒度 |
|---|---|---|
| 直列にドリフトあり | **星型** | **カット単位**で撮り直せる |
| ドリフトなし | **星型を既定**(実装が単純) | **カット単位** |
| 判定不能 | 保留 | 保留 |

## 4. 併せて実施する挙動プローブ(P1)

第0節の「要求変化量で挙動が切り替わる」という見立てを直接確かめる。

- `B1`(既にC1構図の絵)に対して **C3の構図**(大きな変換)を要求して生成する ×2
- 出力どうしの `mae` が、星型サンプル同士の mae(10〜15。実測済み)と同水準に
  ばらつくかを見る

**判定**: 同水準にばらつけば「入力の素性ではなく要求変化量で挙動が決まる」を支持する。
ばらつかなければ支持しない。**これは本検証の判定には使わない**(原画生成プロンプトの
書き方を決めるための参考データ)。

- `imagen_image` × 2(¥12)

## 5. 既知の限界(先に記録する)

- 各条件1サンプル。星型3値をノイズ推定に使うが**厳密な有意差検定ではない**
- 画像モデルのseedは制御していない
- 照合カット変換そのものが劣化を1段加えるが、**両条件に等しくかかる**ため比較は成立する
- 測っているのは「鎖を伸ばすと劣化するか」であり、実運用の絵の良し悪しではない
