# フェーズ3設計: キャラクターステージ(Blender)

- status: **設計のみ(未実装)**。着手は豆虎GO後
- 目的: マスコット「コトラ」([mascot_kotora_v1.png](mascot_kotora_v1.png))が
  演技するシーンを、生成AI費ゼロ(計算費のみ)で量産できるレンダラー

## 構成

```
台本 → 演出プランナー拡張(シーンに acting 指定を追加)
        {"acting": {"pose": "point_right", "emotion": "surprised", "camera": "dolly_in"}}
              ↓
[Cloud Run Job: Blenderヘッドレス]
  - コトラの3Dモデル(1回だけ制作: VRM/glTF、権利は自前)
  - 演技プリセット辞書(頷く/指差す/驚く/悩む/喜ぶ… 各2〜4秒のアクション)
  - リップシンク: ナレーションwav → 口形素解析(OSS) → 口パクキー
  - カメラパステンプレ(寄り/引き/回り込み/あおり)
  - 背景: モーションエンジンの背景と共通トーン
              ↓
  シーンmp4 → 既存のffmpeg統合パイプラインへ(字幕・テロップは従来どおり)
```

## 原則(このプロジェクトの学びの適用)

1. **AIに絵作りをさせない**: AIが出せるのは
   `pose / emotion / camera` のプリセット名だけ(display planと同方式)
2. 文字は一切3D空間に置かない(テロップ・字幕が担当)
3. キャラの見た目はモデルデータで固定 = 一貫性が構造的に保証される

## 必要な準備(人間の作業)

- コトラの3Dモデル化: 外注 or VRoid系ツールで自作(1回きり)
- 演技プリセットのアニメーション付け(10種目安)

## 費用見積

- 開発: 1〜2週間(モデル制作除く)
- 運用: Cloud Run Job のCPU時間のみ(1シーン数円)
- Veo参照モード(フェーズ2b・実装済み)が「動きの品質は運任せ・費用は秒課金」
  なのに対し、こちらは「動きは固定品質・費用ほぼゼロ」。使い分ける
