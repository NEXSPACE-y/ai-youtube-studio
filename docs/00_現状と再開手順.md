## 1. 30秒で分かる現状

**動くもの**: 解説動画を止め絵+図解+TTSで作って公開承認まで回すパイプライン(ローカル/クラウド両対応)。

**動かないもの**: キャラクターが動くアニメーション。**これが休止の理由**。

2026-08-03に「原画A→原画Bの中割りをVeoにやらせる」手法の成立を実証したが
([08](08_中割り検証_20260803.md))、それで作った検証動画は豆虎に
**「静止画とGIFの複合であってアニメーションではない」**と判定された。

## 6. 環境の復元手順(Mac)

`.env` と `.venv/` は **gitに入っていない**ので、clone しただけでは動かない。

```
brew install ffmpeg-full
brew unlink ffmpeg && brew link --force --overwrite ffmpeg-full
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

**通常の Homebrew `ffmpeg` では動かない**(libass/freetype抜きで `subtitles`/`drawtext`
フィルタが無く、レンダリングが落ちる)。

`.env` の要点(gitignore対象のため、値をここに記録する。**秘匿値は含めない**):

```
APP_MODE=local                              # cloud にすると本番
GCP_PROJECT=ai-youtube-studio-503109
GCP_REGION=asia-northeast1                  # メディアモデルは us-central1(MEDIA_REGION)
VEO_MODEL=veo-3.0-fast-generate-001         # 2026-08-03に変更
COST_TABLE_JSON={"veo_second": 13.1}        # 公式SKU実測値で上書き
DEFAULT_COST_LIMIT_JPY=1500                 # 動かす前提なら3500〜4000が要る
```

クラウドモードには ADC が要る:

```
gcloud auth application-default login
gcloud auth application-default set-quota-project ai-youtube-studio-503109
```

**順序に注意。** `login` を後にすると quota project が上書きされる。

## 7. 費用の実態(2026-08-03時点)

公式SKUカタログ(Cloud Billing API)実測、JPY建て:

| SKU | 単価 |
|---|---|
| Veo 3 Audio Video Generation | 65.498 |
| Veo 3 Video Generation(音声なし) | 32.749 |
| **Veo 3 Fast Video 720p Generation**(音声なし) | **13.100** |

- **音声ありは正確に2倍**。編集は `-map 0:v -map 1:a` でVeoの音声を捨てるため、
  `generate_audio=False` を既定にしてある(コミット `0417624`)
- `costs.py` の既定値 `veo_second = 60.0` は**旧挙動(Veo3+音声)に合っていた値**。
  現在は `COST_TABLE_JSON` で 13.1 に上書きしている

**既知の穴**: パイプライン外で実行した生成は `CostMeter` に記録されない。
2026年7月の実費 ¥5,388 に対しメーター記録は ¥1,554 だった。
