## 0. なぜ事前登録するか

「星型と直列のどちらがキャラを保てるか」は、結果を見てから基準を選べばどちらでも
勝たせられる。手順と閾値を先に固定し、後から動かさないことで判定を成立させる。

## 1. V2-B: 測定方法(先に確定)

`tools/genga_interp/consistency_metrics.py` の2指標を使う。Pillowのみで実装し、
外部依存を増やさない。

| 指標 | 定義 | 性質 |
|---|---|---|
| `mae` | 平均絶対差(0-255)。512x512に揃えて全チャンネル平均 | 構図固定下では見た目の差に比例。位置ずれに敏感 |
| `hist` | 64ビン色ヒストグラムのL1距離を0-1に正規化 | 位置ずれに鈍く、色・パレットの変化に敏感 |

**2指標を併記する。** 片方だけでは誤判定するため(構図が僅かにずれると `mae` は跳ねるが、
パレットが同じなら `hist` は動かない)。

### 構図を固定する理由

実際のカットは背景も画角も違うため、画像全体を比較すると**背景の差を測ってしまい、
キャラの差が測れない**。そこで検証では**同一の構図指示**を使い、
条件間の差がキャラのドリフトのみに帰属するようにする。

## 2. V2-A: 鎖の形(星型 vs 直列)

### 手順

基準画像 = 栞の正史立ち絵 `docs/characters/host_deform_sd.png`
生成指示 = 全条件で同一の1文(構図・背景・画角をすべて固定した「照合カット」)

```
星型   canon → S1        canon → S2        canon → S3      (すべて世代1)
直列   canon → D1   D1 → D2   D2 → D3                      (世代1 / 2 / 3)
```

計6枚。`imagen_image` × 6。

### なぜこの形か

星型の S1/S2/S3 は「世代1を3回引いた」サンプルであり、**その散らばりが生成の
ノイズ下限**になる。直列の D3(世代3)がこのノイズ範囲を超えて基準から離れていれば、
ドリフトはノイズではなく世代の累積によるものと言える。

### 判定基準(事前確定)

すべて「正史立ち絵に対する距離」で測る。

1. **ノイズ下限** = 星型3枚の `mae` の最小値〜最大値の幅、および `hist` の同様の幅
2. **直列にドリフトあり** と判定する条件:
   - `D3` の `mae` が星型の `mae` 最大値を **2.0 以上**上回る **かつ**
   - `D3` の `hist` が星型の `hist` 最大値を **0.02 以上**上回る
3. **2指標の向きが一致しない場合は「判定不能」**とし、どちらの形も採用しない
4. 併せて `D1 < D2 < D3` の単調増加が `mae` で成立するかを補助的に見る
   (単調でなければ累積ではなく偶然の可能性が高い)

### 結果の意味(事前確定)

| 判定 | 採用する鎖 | §9-3 差し戻し粒度 |
|---|---|---|
| 直列にドリフトあり | **星型**(各原画Aは正史から直接) | **カット単位**で撮り直せる(カットが独立するため) |
| ドリフトなし | 星型・直列いずれも可。**星型を既定**とする(実装が単純なため) | **カット単位** |
| 判定不能 | 保留。サンプル数を増やして再検証 | 保留 |

### 既知の限界(先に記録する)

- 各条件1サンプルのため統計的な検出力は低い。星型3枚をノイズ推定に使うことで
  部分的に補うが、**厳密な有意差検定ではない**
- 生成モデルの乱数は制御していない(画像モデルにseed指定を渡していない)
- 判定できるのは「世代を重ねると劣化するか」であり、**実カット(背景が異なる)での
  一貫性そのものではない**

## 3. V2-C: `reference_images` の効果

### 手順

2026-08-03 に実証済みの A→B 中割り(`docs/08`)と、同じ原画A・同じ尺・同じseedで
条件だけ変えて比較する。

| 条件 | 渡すもの |
|---|---|
| 実証済み(基準) | `image`=原画A + `last_frame`=原画B |
| 検証 | `image`=原画A + `reference_images`=[栞の正史立ち絵] (`last_frame` なし) |

`veo-3.1-lite` / 8秒 / `generate_audio=False`。`veo_second` × 8。

### 判定基準(事前確定)

両方の**最終フレーム**を取り出し、正史立ち絵に対する `mae` / `hist` を比較する。
加えて**目視で以下の4点**を確認し、記録する(主観だが項目を先に固定する)。

1. 眼鏡の形が保たれているか
2. 髪型・髪色が保たれているか
3. 服(グレーのカーディガン)が保たれているか
4. 破綻(指・輪郭の崩れ)が無いか

- `reference_images` 側が4点すべて満たし、かつ2指標とも基準と同等以下 →
  **採用。原画Bの生成が不要になり1カットあたり画像1枚ぶん安くなる**
- いずれか満たさない → **不採用。原画の鎖(A→B)で進める**
