# 使い方(制作フロー)

管理画面を開くと案件一覧が表示される。1本の動画は以下の流れで進む。
**太字は人間(豆虎)の判断ポイント** — AIは承認を代行しない(要件13章)。

## 1. 企画(状態: 企画中)

案件一覧のフォームにテーマのヒントを入力 →「企画案を生成」。
タイトル候補・想定視聴者・独自の切り口・類似案件の重複警告が表示される。

→ **採用 / 保留 / 却下 を判断**。採用で調査へ。

## 2. リサーチ(調査中)

「リサーチ実行」でGeminiがGoogle検索を使って情報収集。
各項目は「事実 / 推測 / 演出」に区分され、情報源URL付きで表示される。

→ **情報源を開いて確認**してから「台本作成へ」。

## 3. 台本(台本確認待ち)

8セクション構成(フック→結論提示→背景→進行→転換点→結果→教訓→締め)で生成。
各セクションはその場で修正できる。

→ **台本を承認**するとシーン分割(映像構成)が走る。差し戻しも可(理由必須)。

## 4. 素材生成(素材生成中)

「素材生成を実行」。AI動画(Veo)はフックと転換点だけに使われ、
他は静止画+図解でコストを抑える(追補2章)。

- 上限(既定¥1,500/本)を超えそうになると**自動停止**し、承認ボタンが出る
- 再実行は未生成分のみ(部分再生成)

## 5. 編集(編集中→品質確認中)

「編集へ進む」でffmpegが映像・音声・BGM・字幕を合成し、mp4を生成。

## 6. 品質確認(品質確認中)

プレビューを再生し、チェックリスト(映像破綻・読み間違い・字幕同期・BGM音量など)を確認。

→ **合格**で投稿情報が自動生成され公開承認へ。**不合格**なら工程を選んで差し戻し。

## 7. 公開承認 = 豆虎Gate(公開承認待ち)

完成動画・サムネイル・投稿情報(修正可)・情報源・独自要素を1画面で確認し、
9項目のチェックリストを埋めて**「承認して公開する」**。

- チェックが1つでも欠けると公開されない
- クラウドでは投稿サービスが承認レコードを再検証してから、
  非公開アップロード→公開の順で実行される

## 8. 分析(投稿済み)

視聴回数・総再生時間などは自動取得。インプレッション・CTR・維持率は
YouTube Studioで目視(取れない指標は推測で埋めない: 追補6章)。

## 差し戻し・保留・中止

- 各確認画面から理由付きで任意の工程へ差し戻せる。下流の成果物は削除せず
  「不採用」として保持される(監査用: 追補5章)
- 投稿後に問題が出たら「修正必要」へ落として工程を選び直す
